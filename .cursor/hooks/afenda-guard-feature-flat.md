# GUARD — feature package flat naming

GUARD 5 (`pnpm guard:packages`) — three layout modes:

| Mode | Structure |
| ---- | --------- |
| **single-feature** | `src/` flat |
| **multi-feature** | `src/features/<slice>/` flat |
| **tiered-feature** | `src/<feature>/<sub-feature>/` flat (HR Suite) |
